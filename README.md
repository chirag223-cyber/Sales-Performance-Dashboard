# 📊 Sales Performance Dashboard (Power BI)

## Overview

This project is an interactive multi-page Power BI dashboard developed for sales analysis.

The dashboard provides executive insights into sales performance, customer behavior, product profitability, and regional performance.

---

## Dashboard Pages

### Executive Dashboard

- Total Sales
- Total Profit
- Total Orders
- Profit Margin
- Monthly Sales Trend
- Sales by Region
- Product Performance

---

### Product Analysis

- Top Products
- Profit by Product
- Sales by Category
- Scatter Analysis
- Product Matrix

---

### Customer Analysis

- Top Customers
- Sales by Segment
- Customer Profitability
- Average Order Value

---

### Regional Analysis

- Sales by Region
- Profit by Region
- Sales Trend
- State Analysis

---

### Executive Insights

- Highest Sales Region
- Highest Profit Category
- Best Selling Product
- Most Profitable Customer
- Executive Summary
